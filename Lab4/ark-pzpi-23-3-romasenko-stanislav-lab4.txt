3 ОПИС ВИКОНАНОЇ РОБОТИ
1. Текстовий опис інженерних рішень
1.1 Опис архітектурних рішень IoT клієнта
IoT клієнт побудований як Console Application на базі .NET. Архітектура клієнта базується на модульному підході:
▪Модуль конфігурації (DeviceSettings): зберігає ідентифікатор пристрою, прив’язку до конкретної кімнати та URL-адресу сервера.
▪Комунікаційний модуль (IotService): відповідає за підтримку постійного з'єднання з сервером у реальному часі.
▪Виконавчий модуль (Бізнес-логіка): імітує роботу фізичного реле розумного замка.
1.2 Пояснення вибору методів комунікації та протоколів
Для зв'язку було обрано протокол SignalR (WebSockets).
▪Чому не HTTP? Традиційні HTTP-запити потребують постійного опитування сервера пристроєм (polling). SignalR дозволяє серверу самостійно ініціювати команду (Push), що забезпечує миттєве розблокування дверей при успішному бронюванні.
▪Мережевий рівень: Використано асинхронну модель обробки подій, що дозволяє клієнту залишатися чуйним до команд користувача в консолі, одночасно слухаючи сервер.


2. Графічні ілюстрації
2.1 UML діаграма прецедентів
Діаграма описує основні можливості взаємодії з клієнтом:
1.Актори: Користувач (через API), Адміністратор (локально), Система (Сервер).
2.Прецеденти:
▪З'єднання з сервером (автоматично).
▪Прийом сигналу розблокування (від сервера).
▪Зміна ID кімнати (налаштування).
▪Скидання до заводських налаштувань.
▪Ручне тестування замка.

2.2 UML діаграма діяльності
Відображає життєвий цикл роботи пристрою:

2.Спроба підключення до Hub.
3.Паралельні потоки: очікування команд від сервера та очікування вводу користувача в меню.

3. Фрагменти програмного коду
3.1 Бізнес-логіка IoT клієнта (обробка команд та зв'язок)
Цей код реалізує підключення та реакцію на повідомлення сервера.
// Фрагмент IotService.cs
_connection = new HubConnectionBuilder()
    .WithUrl(_settings.ServerUrl, options => {
        // Обхід перевірки SSL для локальної розробки
        options.HttpMessageHandlerFactory = (handler) => {
            if (handler is HttpClientHandler clientHandler)
                clientHandler.ServerCertificateCustomValidationCallback = (m, c, ch, e) => true;
            return handler;
        };
    })
    .WithAutomaticReconnect()
    .Build();
// Слухач команди від сервера
_connection.On<int>("ReceiveUnlockCommand", async (roomId) => {
    if (roomId == _settings.RoomId) {
        await ExecuteUnlockAsync();
    }
});
private async Task ExecuteUnlockAsync() {
    Console.ForegroundColor = ConsoleColor.Green;
    Console.WriteLine($"[{DateTime.Now:T}]СИГНАЛ:Двері розблоковано!");
    Console.ResetColor();
    await Task.Delay(5000); // Імітація відчинених дверей
    Console.ForegroundColor = ConsoleColor.Red;
    Console.WriteLine($"[{DateTime.Now:T}] СИГНАЛ: Двері автоматично заблоковано.");
    Console.ResetColor();
}
